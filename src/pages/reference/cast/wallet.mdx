Usage: cast wallet [OPTIONS] <COMMAND>

Commands:
  new               Create a new random keypair [alias: n]
  new-mnemonic      Generates a random BIP39 mnemonic phrase [alias: nm]
  vanity            Generate a vanity address [alias: va]
  address           Convert a private key to an address [aliases: a, addr]
  derive            Derive accounts from a mnemonic [alias: d]
  sign              Sign a message or typed data [alias: s]
  sign-auth         EIP-7702 sign authorization [alias: sa]

  import            Import a private key into an encrypted keystore [alias: i]
  list              List all the accounts in the keystore default directory
                    [alias: ls]
  session           Manage temporary Tempo wallet sessions
  remove            Remove a wallet from the keystore [alias: rm]
  private-key       Derives private key from mnemonic [alias: pk]
  public-key        Get the public key for the given private key [alias: pubkey]
  decrypt-keystore  Decrypt a keystore file to get the private key [alias: dk]
  change-password   Change the password of a keystore file [alias: cp]
  help              Print this message or the help of the given subcommand(s)

Options:

Display options:
      --color <COLOR>

          Verbosity level of the log messages.

          Depending on the context the verbosity levels have different meanings.
          
          For example, the verbosity levels of the EVM are:
          - 2 (-vv): Print logs for all tests.
          - 3 (-vvv): Print execution traces for failing tests.
          - 4 (-vvvv): Print execution traces for all tests, and setup traces
          for failing tests.
          - 5 (-vvvvv): Print execution and setup traces for all tests,
          including storage changes and
            backtraces with line numbers.
