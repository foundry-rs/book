## `getBlobBaseFee`

### Signature

```solidity
function getBlobBaseFee() external view returns (uint256 blobBaseFee);
```

### Description

Returns the current `block.blobbasefee`.

Use this instead of `block.blobbasefee` after [`vm.blobBaseFee`](/reference/cheatcodes/blob-base-fee): the compiler assumes `block.blobbasefee` is constant within a transaction and may optimize repeated reads away, so it can return a stale value. See [foundry#6180](https://github.com/foundry-rs/foundry/issues/6180).

### Returns

| Name          | Type      | Description                    |
|---------------|-----------|--------------------------------|
| `blobBaseFee` | `uint256` | The current blob base fee      |

### Examples

```solidity [test/GetBlobBaseFee.t.sol]
function testGetBlobBaseFee() public {
    uint256 current = vm.getBlobBaseFee();
    vm.blobBaseFee(current + 1);
    assertEq(vm.getBlobBaseFee(), current + 1);
}
```
