## `getEvmVersion`

### Signature

```solidity
function getEvmVersion() external pure returns (string memory evm);
```

### Description

Returns the EVM version used to execute the current test or script, as a lowercase hardfork name (e.g. `"cancun"`, `"prague"`).

This is the execution EVM version, which is not necessarily the one the contracts were compiled for. It follows `evm_version` in `foundry.toml` or `--evm-version`, and changes after [`setEvmVersion`](/reference/cheatcodes/set-evm-version).

### Returns

| Name  | Type     | Description                    |
|-------|----------|--------------------------------|
| `evm` | `string` | The execution EVM version name |

### Examples

```solidity [test/GetEvmVersion.t.sol]
// forge test --evm-version cancun
function testGetEvmVersion() public {
    assertEq(vm.getEvmVersion(), "cancun");
}
```

### Related Cheatcodes

- [`setEvmVersion`](/reference/cheatcodes/set-evm-version) - Sets the execution EVM version
