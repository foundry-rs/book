## `resumeTracing`

### Signature

```solidity
function resumeTracing() external view;
```

### Description

Resumes the collection of call traces after [`pauseTracing`](/reference/cheatcodes/pause-tracing). Calls made after `resumeTracing` appear in the trace output again.

Calling `resumeTracing` when tracing is not paused has no effect. When traces are not being collected, for example below `-vvvv`, the cheatcode does nothing.
