## `shuffle`

### Signature

```solidity
function shuffle(uint256[] calldata array) external returns (uint256[] memory);
```

### Description

Returns a copy of `array` with its elements in random order. The input array is not modified.

The RNG is seeded randomly on each run unless a seed is set via [`setSeed`](/reference/cheatcodes/set-seed) or the `[fuzz] seed` setting in `foundry.toml`, in which case the order is deterministic.

### Parameters

| Parameter | Type        | Description           |
|-----------|-------------|-----------------------|
| `array`   | `uint256[]` | The array to shuffle  |

### Returns

| Type        | Description                                      |
|-------------|--------------------------------------------------|
| `uint256[]` | A new array with the same elements in random order |
