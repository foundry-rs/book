## `sort`

### Signature

```solidity
function sort(uint256[] calldata array) external returns (uint256[] memory);
```

### Description

Returns a copy of `array` sorted in ascending order. The input array is not modified.

### Parameters

| Parameter | Type        | Description           |
|-----------|-------------|-----------------------|
| `array`   | `uint256[]` | The array to sort     |

### Returns

| Type        | Description                                  |
|-------------|----------------------------------------------|
| `uint256[]` | A new array with the elements in ascending order |
