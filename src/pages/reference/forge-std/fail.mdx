## `fail`

### Signature

```solidity
function fail() internal virtual;
function fail(string memory message) internal virtual;
```

### Description

Mark the current test as failed when execution reaches a branch that should not run. Use `fail()` without a message, or `fail("reason")` to include a custom assertion message.

The message overload requires **forge-std v1.10.0 or later**. If you use an older forge-std dependency, use `fail()` or `assertTrue(false, "reason")`, or update the dependency with `forge update forge-std`. Updating the Forge binary alone does not update your project's forge-std library.
